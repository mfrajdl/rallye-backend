# Etapa 4c – původní HTML instrukce a obrázky

Etapa 4c byla dokončena a uživatelem PostgreSQL ověřena. Její původní HTML/UUID
kontrakt byl následným schváleným zadáním nahrazen Markdownem a názvy souborů.
Nepoužívejte původní `instructionsHtml` ani UUID URL obrázků.

Aktuální instrukce, bezpečné renderování, soukromé obrázky a příklady API:
[templates-markdown.md](templates-markdown.md).
Společný kontrakt šablon, konfigurace a duplikování:
[templates-4d.md](templates-4d.md).

V18 zůstává beze změny; navazující V19 zahazuje výslovně postradatelný testovací
obsah a zavádí nový kontrakt. Neprovádí se HTML → Markdown konverze.
